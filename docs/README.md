# GitHub-ready Maccabist asset bundle v3

This pack is arranged as a repo-ready structure.
You can drop the folders directly into the repository.

## Main folder to use
`public/assets/maccabist/players/`

## Coverage delivered
### Outfield players
- Ages: child, youth, adult
- Poses: hero, celebration
- Colors: green, yellow, red, blue, white, black

### Goalkeepers
- Ages: child, youth, adult
- Poses: ready, celebration
- Colors: blue, pink, purple, black

## Important note
For immediate integration and consistency, each age bucket contains a complete working asset matrix.
That means Claude can already select by age + role + pose + color without waiting for more art.

The `bonus` folder also includes additional alternate renders and previews if you want to swap some specific screens later.
